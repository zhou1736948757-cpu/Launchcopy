## Purpose and limits
Distinguish native event arrival, overlay release handling, synchronous owner commit stages, return, next main-queue turn and first observed viewWillDraw notification. A viewWillDraw notification is a pre-draw boundary, NOT completed display/scanout. No physical300ms root cause or fix is inferred from unit tests or this notification. See [Apple NSEvent timestamp](https://developer.apple.com/documentation/appkit/nsevent/timestamp) (system-start event clock; related systemUptime), [ProcessInfo.systemUptime](https://developer.apple.com/documentation/foundation/processinfo/systemuptime) and [viewWillDraw](https://developer.apple.com/documentation/appkit/nsview/viewwilldraw()). Sleep/domain mismatches are not certified.
