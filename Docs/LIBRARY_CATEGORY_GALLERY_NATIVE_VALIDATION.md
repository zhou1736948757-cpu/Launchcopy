# Category gallery native validation

Date: 2026-10-19. This is a protocol, not a passed result.

## Artifact and ownership
Use only the newly frozen, packaged library-gallery candidate after serial verification. Confirm exact old owned process and quit it normally through CUA, verify absence, then launch the new exact candidate through CUA. Never replace/install the formal app or send process signals. Ordinary non-topmost window, independent gui profile. Reuse only249 hash-verified authored fixture files; copied synthetic app metadata may be categorized across eight supported groups. Do not import preferences, histories, caches or private pixels. Enable Library only through its own test Settings; history remains off.

## Native controls
1. Default Library off/activity off. Enable Library and observe save receipt.
2. Overview shows populated rounded glass cards, large icons and mini clusters; no default sidebar/opaque result table. Caption and search readable over current backdrop; inspect inline only.
3. Category/mini cluster opens its existing result browser without launching an app. Back returns overview, not outer grid. Query changes use independent results; clear/Escape restores overview, final Escape returns outer grid.
4. Existing details and actions remain available; verify non-destructive details/back controls. Optional direct launch only on an authored inert fixture, never a real personal app for this packet.
5. New candidate ordinary main-grid return has no detached Library control/field editor in AX. Inspect screenshot for residual blue ring after completed Back/Escape; these are not proof of physical swipe rendering.
6. Real touchpad: enter, focused search, partial horizontal swipe canceled to Library, completed swipe to grid. Check blue residual both during motion and after completion. Keep native vertical scroll and outer page parameters unchanged. Only user/actual observation can accept this gate; generated scroll non-effect is inconclusive, not a pass.
7. Where possible inspect narrow and large window layout using normal UI, keyboard/Tab and current language. Do not change OS accessibility preferences solely to force a gate. Reduced-transparency/contrast flags remain source-level unless actually exercised.

## Evidence discipline
Separate mounted-window ownership tests, source review, full tests/build/package and native/human outcomes. No claimed FPS, 120Hz, physical smoothness, VoiceOver or private-wallpaper causality from these checks. Preserve source/executable fingerprints; final profile state and unresolved gates go into native-results.json and the stage summary. No saved desktop screenshots.
